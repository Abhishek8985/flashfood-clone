# Flashfood-clone
This project features a responsive and visually appealing web page layout, designed using modern CSS techniques. It incorporates a sticky navigation bar, dropdown menus, and interactive elements to enhance user experience. The layout is styled with a clean and vibrant color palette, making it suitable for various applications, from portfolios to business websites.

Key Features
Sticky Navigation Bar: A sticky header that remains at the top of the viewport while scrolling, ensuring easy navigation.
Dropdown Menus: Interactive dropdown menus that reveal options on hover, enhancing navigation and accessibility.
Responsive Design: The layout is designed to adapt to different screen sizes, providing a consistent user experience across devices.
Hover Effects: Subtle hover effects on buttons and links improve interactivity and visual feedback.
Image Backgrounds: Utilizes background images to create engaging sections and visual interest throughout the page.
Custom Fonts: Incorporates the Figtree variable font for a modern typographic style.
